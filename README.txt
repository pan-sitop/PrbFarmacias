FARMACIAS COLQUE — SITIO WEB COMPLETO
====================================

PÁGINAS INCLUIDAS
- index.html: Inicio con carrusel de tres diapositivas.
- productos.html: catálogo y punto de venta de demostración.
- inventario.html: tabla, alertas y reposición.
- marco-teorico/index.html y 7 subpáginas:
  introduccion.html, antecedentes.html, planteamiento.html,
  formulacion.html, proposito.html, metodologia.html, planificacion.html.
- analisis-estructurado/index.html y subpáginas:
  modelo-ambiental.html, modelo-comportamiento.html.
- orientado-objetos/index.html y subpáginas:
  diagramas-clases.html, casos-uso.html.
- video.html
- contacto.html

DÓNDE PONER LAS IMÁGENES
Guarda las fotos del carrusel en:
  assets/img/farmacia-1.jpg
  assets/img/farmacia-2.jpg
  assets/img/farmacia-3.jpg

Las imágenes del carrusel ya están enlazadas a esos nombres en assets/css/style.css. Usa fotografías propias o imágenes con licencia adecuada, idealmente panorámicas (por ejemplo, 1600 x 900 px). Si no pones imágenes, se mostrarán los fondos de color de respaldo.

Portada del video opcional:
  assets/img/video-portada.jpg

Video local opcional:
  assets/video/presentacion.mp4

CÓMO ABRIR
1. Descarga el ZIP y extrae la carpeta.
2. Mantén la estructura de carpetas intacta.
3. Abre index.html en Chrome o Edge, o abre la carpeta en Visual Studio Code y utiliza Live Server.
4. La fuente Google Fonts necesita internet; el sitio y sus funciones JavaScript están en archivos locales.

FUNCIONES
- Navbar adaptable con menús desplegables y subpáginas.
- Carrusel automático con botones anterior/siguiente y puntos.
- Catálogo con búsqueda y filtro por categoría.
- Carrito y registro simulado de ventas.
- Actualización local del inventario, reposición y alertas.
- Formularios y diagramas académicos.

IMPORTANTE
Este es un prototipo educativo. Los productos, precios y cantidades son ejemplos, no cotizaciones actuales verificadas ni indicaciones médicas. Los cambios de inventario se guardan solo en localStorage del navegador utilizado. No es un sistema listo para gestionar una farmacia real: faltan backend, base de datos central, seguridad, autenticación, facturación, trazabilidad por lote, vencimientos y validaciones regulatorias.
